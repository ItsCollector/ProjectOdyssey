# Project Odyssey

A rewrite of my C# VSRG engine that I created during Uni. Doing it from scratch as I am implementing things that I've learnt and should of done in hindsight. 

Transparency in AI usage
- I use Claude for assistance in finding bugs and writing tests, but the majority of code is hand-written by me.
- I AI generate shitty temporary assets for testing, with the intention on creating better ones myself when the game is more developed. I plan for everything to be skinnable, including menus and all buttons you can customise the visuals to your liking. The infrastructure for everything being skinnable exists already, but its not fully fleshed out.
- I use Claude to read diagnostic logs provided by the game to find performance issues in particular areas due to the logs having 10s of thousands of frames to analyse.
